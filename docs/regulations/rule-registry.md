# 규칙 레지스트리 — 규칙 하나에 주인 문서 하나

> 2026-11-27 대표 결정. 모든 계약서·행정 처리는 회사규정을 바탕으로 한다.
> 같은 규칙은 **한 문서에만** 적고, 다른 문서는 문서 코드(예: CP-03)로 가리키기만 한다.
> 숫자(일수·%·금액·기한)를 고치려면 아래 표에서 **주인 문서**를 찾아 그 한 곳만 고친다.

## 1. 문서 우선순위

| 순위 | 문서 | 정하는 것 |
|---|---|---|
| 1 | 계약서 「계약 내용」(별지) | 그 계약에만 해당하는 범위·기간·주기·금액·결제 방식 |
| 2 | 계약서 본문 (압축판 10조) | 기간·자동 연장, 대금·결제 기일, 대금 조정, 중도 해지 정산식, 배상 한도, 준거 문서 |
| 3 | CP-01 서비스 이용약관 | 모든 고객 공통 절차·원칙 |
| 4 | CP-02 · CP-03 · CP-04 · CP-05 세부 정책 | 주제별 구체 기준과 숫자 |
| 5 | OP-xx 운영 매뉴얼 | 직원 절차. 고객에게 의무를 지우지 않음 |

우선순위 조항의 원본은 CP-01 제4조. 다른 문서는 "우선순위는 CP-01에 따른다"고만 쓴다.

## 4. 결정 기록 (2026-11-27)

- 클레임·하자 통지 기한 **7일**로 통일 (종전 약관 24시간, OP-07·09 3일 폐기)
- 배상 한도는 정기·1회성 모두 **배상책임보험 보상 한도**로 통일 (월 계약금 10배 폐기)
- CP-03 일정 변경 승인 시 대체 시공일 범위 **30일**
- 예약금은 **잔금에서 차감** (시공 후 환급 방식 폐기)
- 공식 결제 수단은 법인 계좌·카드·가상계좌·세금계산서/현금영수증. 개인 계좌·무증빙 현금은 규정에 두지 않음
- OP-06 · OP-07 · OP-08 폐지 (CP-03 · CP-01 · CP-05 로 흡수)
- OP-04 장기 할인율(2년차 15%, 3년차 25%) 삭제 (2026-11-25 재구매 조항 삭제 결정과 정합)
- CP-04 의 계약서 조 번호 참조를 모두 문서 코드 참조로 변경

## 5. 앱 연동 할 일 (4단계)

1. 공개 규정 페이지 `/policy/[code]` (버전별 주소 포함) — 약관규제법 명시·교부 요건
2. 계약서 서명 전 "중요 내용 확인" 체크 4개 + 준거 문서 열람 확인, 시각 기록
3. 계약서 스냅샷(`contract_snapshot`)에 참조한 규정의 version id 저장 — 서명 당시 버전 고정
4. 계약서 양식에 `{{환불기준표}}` 등 변수를 두고 CP-03 현재 버전에서 자동 주입 — 숫자 출처 하나로
5. 규정 CP-01·02·03·04·05 초안 검토 후 발행(published) 전환

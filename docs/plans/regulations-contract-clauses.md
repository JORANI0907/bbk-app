# 근로·용역계약서 양식에 넣을 회사 규정 참조 조항 (초안, 2026-11-23)

규정 동의는 별도 화면 대신 **계약서 조항**으로 받기로 함(대표 결정). 아래 문안은 회사 규정(HR-01~05)이 관리자 화면에서 **발행된 뒤**에 계약서 양식(contract_templates, party_type=worker)에 반영한다. 발행 전에는 적용하지 않는다.

관련 메모: 규정 시스템 구조는 `scripts/regulations-seed/README.md`, 원고 검토 메모는 `outputs/보고서/회사규정_검토메모_2026-11-23.md`.

## 공통 원칙

- 계약서는 규정의 **코드와 판(版)** 을 적는다. 예: "HR-03 안전보건관리규정(제1판, 2026-12-01 시행)". 규정이 개정되면 계약서를 다시 쓰지 않고, 개정 규정은 제20조(통지) 방식으로 알린다.
- 근로계약서(정규직·계약직·단시간·초단시간·일용직)에는 "회사 규정을 열람하였고 이에 따른다"를 넣는다.
- **프리랜서 용역계약서에는 취업규칙·복무규정을 적용하지 않는다.** 대신 "계약상 의무"로서 안전 기준·개인정보 수칙·고객 응대 기준의 준수를 약정한다(HR-01 제8조 ③·제9조와 일치시켜 근로자성 요소를 만들지 않기 위함).
- 지금 양식에 있는 "회사규정·취업규칙을 준수한다"는 문구는 **취업규칙이 실제로 없으므로** 아래 문안으로 바꾼다.

## 양식별 문안

### 1. 정규직 근로계약서 — 제9조 (성실의무 및 비밀유지) 1) 교체

현행: `1) 을은 갑의 지시에 따라 성실히 근무하고 회사규정·취업규칙을 준수한다.`

변경:
```
1) 을은 갑의 지시에 따라 성실히 근무하며, 갑이 BBK 공간케어 앱 「회사 규정」에 게시한 다음 규정을 열람하였고 이에 따른다.
   - HR-02 일용직 근로·임금·근태 기준 중 근태·안전 관련 조항 (정규직에 준용)
   - HR-03 안전보건관리규정
   - HR-04 개인정보 내부관리계획
   - HR-05 직장 내 괴롭힘·성희롱 예방 기준
   - OP-01 작업 전·중·후 수칙, OP-02 현장 예절 및 복장 수칙, OP-03·OP-09~OP-11 민원·클레임 대응 규정
2) 규정이 개정된 경우 갑은 시행일 전에 앱 알림 또는 문자로 알리며, 을은 개정 규정에 따른다. 다만 을에게 불리한 변경은 을의 동의를 받는다.
```
→ 기존 2)·3)은 3)·4)로 번호 조정. 상시 근로자 10인 이상이 되어 취업규칙을 제정하면 "HR-00 취업규칙"을 맨 앞에 추가한다.

### 2. 계약직(기간제) 근로계약서 — 제9조 1) 교체
정규직과 동일 문안. 기간제 특성상 "계약기간 중" 문구만 추가:
```
1) 을은 계약기간 중 갑이 앱 「회사 규정」에 게시한 규정(HR-02·HR-03·HR-04·HR-05, OP-01~OP-03, OP-09~OP-11)을 열람하였고 이에 따른다.
```

### 3. 단시간 근로계약서(주 15시간 이상) / 4. 초단시간 근로계약서(주 15시간 미만)
현행 양식에 규정 조항이 없으면 "성실의무" 조에 아래 1개 항 추가:
```
을은 갑이 앱 「회사 규정」에 게시한 HR-02(근태·임금 기준)·HR-03(안전보건)·HR-04(개인정보)·HR-05(괴롭힘·성희롱 예방) 및 현장 운영 규정(OP-01~OP-03, OP-09~OP-11)을 열람하였고 이에 따른다.
```

### 5. 일용직 근로계약서 — 제7조·제8조 보강
제7조 (안전수칙 준수) 1) 뒤에 추가:
```
안전교육과 보호구 착용의 세부 기준은 HR-03 안전보건관리규정에 따르며, 을은 작업 전 앱에서 해당 규정을 열람한다.
```
제8조 (성실의무·비밀유지) 교체:
```
을은 고객 정보·현장 정보(출입방법·비밀번호 포함)를 누설하지 아니하며, 그 취급 기준은 HR-04 개인정보 내부관리계획에 따른다. 근태·일당·취소 시 처리 기준은 HR-02 일용직 근로·임금·근태 기준에 따른다. 위반 시 손해배상 책임을 진다.
```
→ HR-02 제20조에서 사장님이 "자율 적용"을 결정한 항목(야간 가산, 당일 취소 50% 등)은 제4조·제5조 숫자를 그 결정과 맞춘다. 현행 양식 제4조 "연장 시 통상시급 50% 가산"은 5인 미만에서는 법정 의무가 아니므로 결정 결과에 따라 유지 또는 삭제.

### 6. 프리랜서 용역계약서(3.3%) — 제3조 보강 + 제9조 수정 + 안내문 교체

제3조 (업무 범위) 2) 뒤에 추가:
```
4) 갑이 정하는 결과물 품질 기준·안전 기준·개인정보 수칙은 HR-01 프리랜서(위탁) 운영 기준 제9조의 범위(HR-03 안전보건관리규정, HR-04 개인정보 내부관리계획, OP-01~OP-03·OP-09~OP-11 현장 운영 규정)에 한하며, 이는 결과물에 대한 계약상 요구이고 작업 과정의 지휘·감독이 아니다. 갑은 을에게 취업규칙·복무규정·징계규정을 적용하지 아니한다.
5) 배정 제안의 수락·거절, 보수 정산, 비용 부담, 대체 인력, 해지 절차는 HR-01 프리랜서(위탁) 운영 기준에 따르며, 을은 계약 체결 전 앱에서 해당 기준을 열람한다.
```
제5조 1) "건별 또는 시간당 {{WORKER_HOURLY_WAGE}}원" → HR-01은 **건별 단가**를 원칙으로 하므로 "시간당" 표현은 삭제하거나 "건별 {{단가}}원"으로 변수 교체 검토(시간당 보수는 근로자성 요소로 평가될 수 있음 — 노무사 확인).
제9조 2) "갑은 산재보험 미가입 사업주에 해당" → HR-01 제13조(산재 임의가입·단체상해보험 [확인] 항목) 결정 결과와 맞춘다. 결정 전에는 수정하지 않는다.
하단 경고문(⚠ 근로자성 판정 위험)은 유지하되 "자세한 운영 기준은 HR-01 참조" 한 줄 추가.
제12조 (기타)에 추가: `본 계약과 HR-01 운영 기준이 다를 때는 본 계약이 우선한다.`

## 적용 절차

1. HR-01~05 발행(관리자 화면) → 판·시행일 확정
2. 사장님이 HR-02 제20조 자율 적용 항목, HR-01 제13조 보험 항목 결정
3. 위 문안의 코드·판을 확정값으로 채워 contract_templates 6종 수정 (양식 관리 화면에서 직접, 또는 스크립트)
4. 이미 서명된 계약에는 소급하지 않음. 갱신·신규 계약부터 적용
5. 노무사 검토 항목: 프리랜서 제3조 4)·5) 문안이 근로자성 요소를 만들지 않는지, 제5조 시간당 보수 표현

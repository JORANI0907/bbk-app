# 회사 규정 시드 원고 형식

앱 "회사 규정" 기능(관리자 `/admin/regulations`)에 넣을 원고. 파일 1개 = 규정 1개.
`node --experimental-strip-types scripts/seed-regulations.mjs --apply` 로 DB(regulations / regulation_versions)에 넣는다.

## 파일명

`<코드>.json` — 예: `HR-01.json`, `OP-03.json`, `CP-01.json`

## 코드 체계

| 접두 | 분류(category) | 기본 공개범위(visibility) | 예 |
|---|---|---|---|
| HR | `legal_hr` 법정·인사 | `worker` | HR-01 프리랜서(위탁) 운영 기준 |
| OP | `sop` 운영 규정(SOP) | `worker` | OP-01 작업 전·중·후 수칙 |
| CP | `customer_policy` 고객 약관·정책 | `customer` 또는 `public` | CP-01 서비스 이용약관 |

visibility 값: `admin`(관리자만) · `worker`(직원 포털) · `customer`(고객 포털) · `public`(로그인 없이 외부 공개)

## JSON 구조

```json
{
  "code": "HR-01",
  "title": "프리랜서(위탁) 운영 기준",
  "category": "legal_hr",
  "visibility": "worker",
  "summary": "한 줄 요약 (목록 화면에 표시, 80자 이내)",
  "effective_date": "2026-12-01",
  "change_summary": "제정",
  "review_notes": "노무사 확인이 필요한 조항 목록. 없으면 빈 문자열",
  "html_body": "<h2>제1장 총칙</h2><p><strong>제1조 (목적)</strong></p><p>① ...</p>"
}
```

## html_body 작성 규칙 (전자법령 스타일)

- 장: `<h2>제1장 총칙</h2>` (장이 필요 없을 만큼 짧으면 생략 가능)
- 조: `<p><strong>제1조 (목적)</strong></p>` — 반드시 `제N조 (제목)` 형식. 가지번호는 `제3조의2 (…)`.
- 항: `<p>① …</p>`, `<p>② …</p>` (원문자 ①~⑳). 항이 하나뿐이면 번호 없이 `<p>…</p>`.
- 호: `<p>1. …</p>`, `<p>2. …</p>` — 항 아래 세부 열거.
- 목: `<p>가. …</p>`, `<p>나. …</p>`
- 표가 필요하면 `<table><tbody><tr><td>…</td></tr></tbody></table>` (스타일 속성 없이).
- 부칙: 맨 끝에 `<h2>부칙</h2><p>① (시행일) 이 규정은 {{시행일}}부터 시행한다.</p>` — `{{시행일}}` 은 앱이 effective_date 로 치환.
- `<html>`, `<head>`, `<style>`, `<body>` 태그 없이 본문 조각만 쓴다.
- 법령 근거는 조문 안에 괄호로 명시: 예 `(근로기준법 제17조)`. 조문 번호가 확실하지 않으면 법명만 쓰고 `review_notes`에 적는다.
- 회사 표기: "회사" (정의 조항에서 "범빌드코리아 주식회사(이하 "회사")"로 한 번 정의)
- 금액·일수 등 사업주 결정 사항은 `[확인: …]` 표시로 남기고 `review_notes`에 모은다.

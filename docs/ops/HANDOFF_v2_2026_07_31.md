## 5. 알려진 이슈·판단 사항

- **incidents vs claims**: 계획서 §3.4는 "incidents 유형에 'customer_claim' 추가" 였으나, 실제 DB에는 `incident_reports`(직원 사고, 기존)과 `claims`(v2 신설 고객 클레임)이 별개 테이블. 판단상 `/admin/claims` 별도 페이지로 신설했음. 계획서와 실제 매핑이 다름을 사용자에게 이미 설명함.
- **AI 초안 (S2)**: `ANTHROPIC_API_KEY` 환경변수 필요. Vercel 프로덕션에 이미 설정돼 있는지 확인 필요 (기존 finance/import-sheet 에서 사용 중이므로 있을 것).
- **incidents 라우트**: `/admin/incidents`는 그대로 유지 (직원 경위서 용도).
